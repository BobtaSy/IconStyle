How to Apply Custom Colored Icons to Windows Folders

1

Download Native Windows .ICO

Click the blue "Download Windows .ICO" button on any icon below. It directly downloads a genuine 6-resolution `.ico` file (256px down to 16px) that Windows immediately recognizes! (Or pick from the 200 pre-saved .ico files in your local ico/ folder!)

2

Open Folder Properties

Right-click the folder in Windows File Explorer you want to customize and click Properties.

3

Select "Change Icon..."

Navigate to the Customize tab at the top, and click the Change Icon... button at the bottom.

4

Browse and Apply

Click Browse..., select your `.ico` file, click OK, then Apply. Your folder now features a bespoke designer icon!
